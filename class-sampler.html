抽样规则与保存说明

全班编码先随机排列，不重复抽取。依序确认性别，男孩和女孩各取前3名；缺勤或该性别已满时继续下一位。未满额会明确提示。

默认勾选出勤是一项初始设置，不代表已经逐人核实到园。只有现场确认并纳入的6名儿童构成已选名单。

不需要姓名，也不会上传抽样记录。刷新会尝试恢复当前浏览器中的同一份顺序；不跨设备同步，清理浏览器数据会删除记录。请结束后下载记录。

本地打开无需联网。手机通过 GitHub Pages 打开时，首次加载网页需要联网；本页面不提供离线缓存。
